# Briefs de génération IA — style jeu mobile moderne, 2D

Direction artistique visée : **2D moderne stylisée, propre, lisible sur petit écran**, dans l'esprit de jeux mobiles type Brawl Stars / Clash Royale / Raid: Shadow Legends — PAS manhwa/webtoon, pas pixel art.

À utiliser sur Nano Banana, Leonardo AI, ou Higgsfield (image). Adapter le prompt selon l'outil.

---

```
2D mobile game character art, stylized modern fantasy warrior, female,
athletic build, arena gladiator outfit mixing ancient Greek armor with
futuristic materials (metal plates, glowing neon accents), confident
combat pose, clean vector-inspired shading, bold outlines, vibrant color
palette, character select screen style, plain background, high detail

```

---

## Conseils d'utilisation

- Toujours générer d'abord **le personnage principal** et figer le style avant de passer aux adversaires, pour garder une cohérence visuelle sur tout le jeu.
- Une fois un style validé, réutiliser au maximum les mêmes mots-clés de style ("clean vector-inspired shading, bold outlines, vibrant color palette") dans tous les prompts suivants pour éviter la dérive de style d'une génération à l'autre.
- Sur Higgsfield, activer **Soul ID** dès la première bonne génération du personnage principal pour le garder cohérent sur les scènes/situations suivantes.
- Si le style dérive trop, envisager **Scenario** (entraînement sur ta propre bible graphique) pour la production en volume — voir section notes du projet.
